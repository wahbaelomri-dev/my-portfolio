# Rapport de Projet : Création du Portfolio Personnel

## 1. Introduction
Ce projet consiste en la conception et le développement d'un portfolio interactif et responsive, réalisé dans le cadre de ma formation en **BTS DAI**. L'objectif est de présenter mon profil, mes compétences et mes réalisations.

## 2. Technologies Utilisées
* **HTML5 :** Pour la structuration sémantique du contenu (Header, Sections, Footer).
* **CSS3 :** Pour la mise en forme, avec l'utilisation de :
    * **Variables CSS :** Pour une gestion harmonieuse des couleurs (Thème Rose & Brun).
    * **Flexbox :** Pour l'alignement de la barre de navigation.
    * **CSS Grid :** Pour la disposition responsive de la section "Projets".
* **GitHub Pages :** Pour le déploiement et l'hébergement du site en ligne.

## 3. Étapes de Réalisation
1. **Conception :** Choix d'une charte graphique monochrome et moderne.
2. **Développement :** Écriture d'un code propre et commenté.
3. **Optimisation :** Tests de responsivité pour assurer un affichage parfait sur PC et Mobile.
4. **Versionnage :** Utilisation de Git pour suivre les modifications et GitHub pour le partage du code source.

## 4. Conclusion
Ce projet m'a permis d'approfondir mes connaissances en développement Front-End et de maîtriser l'outil de versionnage GitHub, essentiel pour mon parcours en informatique.
